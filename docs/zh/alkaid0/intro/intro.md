# 简介 / Intro

## Alkaid0 是什么

Alkaid0 是一个 **开源的、轻量的、跨平台的、开箱即用的** 基于 Go 的 **系统级** 开源编程 Agent & Harness 内核。其目标旨在为开发者提供一套比 Claude Code 更轻量、易用的开源替代的内核部分。

Alkaid0 与客户端协议的通信基于 AgentClientProtocol v2 扩展。其使用 WebSocket 与客户端进行通信。因此，你可以将任何兼容 ACPv2 的客户端连接到 Alkaid0，也可以使用专为 Alkaid0 设计的客户端以获得完整的功能与体验。

Alkaid0 可在 Windows、Linux 和 macOS(实验性) 上运行，并且支持 x86-64 与 ARM64 架构。

Alkaid0 专为编码任务而生，并针对性进行了优化。**Alkaid0 不是也不会成为一个通用 Agent。**因此，如果你需要大量开发与编码之外的其它功能，不建议使用 Alkaid0 作为 Agent Kernel。

## 优势

### 性能与占用

得益于 Go，Alkaid0 的占用相比于基于 Node 或 Python 的 Agent 非常小。

- 在 Linux 上：后台静默占用 **10MB** 左右，工作占用 **20-50MB** 左右。
- 在 Windows 上：后台静默占用 **25MB** 左右，工作占用 **50-100MB** 左右。

> \*Windows 不支持内存写时复制，因此在多会话运行的情况下，内存占用会显著增加。但仍旧远低于 Claude Code 与 Deepseek Harness。
>
> \*\*macOS 由于没有设备，无法进行测试。

### 功能

特色功能：

- **多会话多客户端**：支持多个不同的客户端连接并操作同一个 Alkaid0 工作会话。
- **原生 LSP 协议支持**：原生支持 LSP 链接并为 AI 操作提供了自动检查等功能。
- **基于表达式的审批规则**：支持类 C 表达式的审批规则，可以灵活地控制 AI 的行为。
- **内置 Codebase 维护**：内置 0 配置的 Codebase 更新与搜索功能，并允许混合 BM25 关键词搜索 与 向量搜索（需配置 embedding 模型）。
- **跨会话历史查询搜索**：支持 AI 在同一工作区内跨会话搜索历史记录。
- **内置跨平台原生沙盒** 内置支持 Windows、Linux 的 0 配置轻量原生命令执行沙盒。
- **基于内置模型的提示词分段**：支持基于内置模型的提示词分段，以避免将大块日志带到用户输入中污染上下文。

其它功能：

- **动态工作流**：支持类 Claude Code 的 dynamic workflow（需要安装 Python）

> Alkaid0 使用了实验性的上下文管理方案，因此缓存命中率和实际费用可能会高于其它 Agent。我们在不断接受反馈并优化。
